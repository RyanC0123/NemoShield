# NemoShield — Backend API Contract

**API Version:** 0.1.0  
**Framework:** FastAPI  
**Development Base URL:** `http://127.0.0.1:8001`  
**Content Type:** `application/json`

## 1. Overview

NemoShield provides REST APIs for retrieving cybersecurity events, analyzing events using NVIDIA Nemotron, retrieving security alerts, and displaying dashboard statistics.

API Documentation:
- Swagger UI: `/docs`
- OpenAPI JSON: `/openapi.json`

## 2. API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| GET | `/api/events` | Retrieve security events with filtering and pagination |
| GET | `/api/events/{event_id}` | Retrieve a single security event |
| POST | `/api/analyze` | Analyze a security event using Nemotron |
| GET | `/api/alerts` | Retrieve security alerts |
| GET | `/api/dashboard/summary` | Retrieve security dashboard statistics |

## 3. Security Events API

### GET /api/events

**Query Parameters**

| Parameter | Type | Default | Constraints |
|---|---|---|---|
| limit | integer | 50 | 1–100 |
| offset | integer | 0 | ≥ 0 |
| severity | string | null | low, medium, high, critical |

**Example Request**

`GET /api/events?limit=2&offset=0&severity=high`

**Response — 200 OK**

```json
{
  "events": [
    {
      "event_id": "EVT-0011",
      "timestamp": "2026-01-15T10:10:00Z",
      "source_ip": "192.0.2.40",
      "destination_ip": "198.51.100.20",
      "event_type": "port_scan",
      "severity": "high"
    }
  ],
  "total": 5,
  "limit": 2,
  "offset": 0
}
```

The response above is illustrative; the actual number of events depends on the requested pagination parameters.

**Errors:** 422, 500.

## 4. Single Security Event API

### GET /api/events/{event_id}

**Path Parameter:** `event_id` (string)

**Example:** `GET /api/events/EVT-0011`

**Response — 200 OK**

Returns one SecurityEvent object with the following fields:

- `event_id`
- `timestamp`
- `source_ip`
- `destination_ip`
- `event_type`
- `severity`

**Errors:** 404, 500.

## 5. AI Analysis API

### POST /api/analyze

**Request Body**

```json
{
  "event_id": "EVT-0011"
}
```

The event ID must match `EVT-XXXX`, where each X represents a digit.

**Response — 200 OK**

```json
{
  "event_id": "EVT-0011",
  "status": "completed",
  "analysis": {
    "summary": "Potential port scanning activity detected.",
    "risk_level": "high",
    "recommended_action": "Review firewall logs."
  }
}
```

The analysis content is generated by Nemotron and may vary between requests. AI assessments should be treated as recommendations, not confirmed attack evidence.

**Errors:** 404, 422, 502, 503, 500.

## 6. Security Alerts API

### GET /api/alerts

**Response — 200 OK**

```json
{
  "alerts": [
    {
      "alert_id": "ALT-EVT-0011",
      "event_id": "EVT-0011",
      "severity": "high",
      "message": "HIGH severity port_scan event requires investigation.",
      "status": "open"
    }
  ],
  "total": 9
}
```

Alerts are generated from high- and critical-severity events in the synthetic dataset. The example shows one alert; the `alerts` array contains all generated alerts.

**Errors:** 500.

## 8. Standard Error Response

NemoShield uses a consistent error format:

```json
{
  "error": {
    "code": "NOT_FOUND",
    "message": "Security event not found"
  }
}
```

| HTTP Status | Error Code | Meaning |
|---|---|---|
| 400 | BAD_REQUEST | Invalid request or business rule |
| 404 | NOT_FOUND | Requested resource does not exist |
| 422 | VALIDATION_ERROR | Request validation failed |
| 500 | INTERNAL_SERVER_ERROR | Unexpected backend error |
| 502 | BAD_GATEWAY | Upstream AI service or response failed |
| 503 | SERVICE_UNAVAILABLE | Required service unavailable |

## 9. Additional APIs

Existing APIs are maintained separately from the five Phase 3 endpoints.

- `/api/agent/chat` — Nemotron general chat
- `/hardware/*` — Arduino control and status
- `/health` — Backend health check

Refer to Swagger UI for their request and response schemas.

## 11. Implementation Notes

- Data source: `data/synthetic_events_v1.json`
- Input validation: Pydantic
- AI provider: NVIDIA Nemotron
- Error handling: Global FastAPI exception handlers
- Alerts: Severity-based rules (high/critical)
- Alert state: Currently generated dynamically, not persisted
- This API version is intended for the NemoShield development MVP.
